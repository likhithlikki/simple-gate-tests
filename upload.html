Upload questions

Accepted file format

A .json file. Questions whose id is already in the sheet are not uploaded; the existing row is left as it is. Questions with a problem are listed and skipped.



      

        

          
FieldNeeded?What to put

          
            
examrequiredExam name, for example GATE. File level, or taken from a question label like GATE EC 2020.

            
branchrequiredFor example EC. File level, or on each question.

            
yearrequiredFour digits, for example 2020. File level, or on each question.

            
subjectrequiredThe topic shown in the topic filter. File level, or on each question.

            
questionsrequiredList of questions. A question's own exam, branch, year and subject win over the file level ones.

            
idrequiredUnique across the whole sheet. Also the image file name: images/<id>.png.

            
question_typerequiredMCQ (one answer), MSQ (many answers) or NAT (numeric).

            
marksrequiredA number above 0.

            
questionrequiredThe question text.

            
optionsMCQ and MSQ onlyAn object {"A": "...", "B": "..."} or a list. Use null for NAT.

            
negative_marksoptionalMarks lost for a wrong MCQ answer. Default 0.

            
answeroptional"B", "A;C" (MSQ), "3.5" or a range "3.4 to 3.6" (NAT). Empty means the question is not scored.

            
imagesoptionalA list. If it is not empty, the exam shows the image named after the id.

            
question_number, answer_format, explanation, source_page, answer_statusoptionalKept as they are.

          
        

      

      
Also accepted: a list of such objects (several exams in one file), or one flat list of questions where every question carries its own exam, branch, year and subject.
