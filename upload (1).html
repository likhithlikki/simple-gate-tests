Accepted file format

The GATE question files: one .json per branch and year (for example CS/2020.json). You can pick many files, or a whole folder at once. Questions whose id is already in the sheet are not uploaded; the existing row is left as it is. Questions with a problem are listed and skipped. manifest.json, source-metadata.json and image-source-map.json are ignored.



      

        

          
FieldNeeded?What to put

          
            
examrequiredFor example GATE. File level.

            
branchfile levelFor example CS. If a file has no branch (UNKNOWN_BRANCH), its questions are saved as branch UNKNOWN.

            
yearfile levelFour digits. If a file has no year (UNMAPPED_YEAR.json), its questions are saved with year Unmapped.

            
subjectfile levelBranch name. Not used as the topic when a question has its own topic.

            
questionsrequiredList of questions.

            
idrequiredUnique across the whole sheet, for example cs202001.

            
topicrecommendedShown in the topic filter, and each topic becomes a section in the exam. Empty means Unclassified.

            
question_typerequiredMCQ (one answer), MSQ (many answers) or NAT (numeric).

            
marksrequiredA number above 0.

            
questionrequiredThe question text. Formulas go between [latex] and [/latex]. May be empty only if the question has an image.

            
optionsMCQ and MSQ onlyAn object {"A": "...", "B": "..."}. Use null for NAT. An option may be empty if it has an image.

            
negative_marksoptionalMarks lost for a wrong MCQ answer. Default 0.

            
answeroptional"B", "A;C" (MSQ), "3.5" or a range "3.4 to 3.6" (NAT). Empty (null) means the question is not scored.

            
imagesoptionalA list of paths. images/questions/<id>_01.jpg shows under the question text. images/options/<id>_A_01.jpg shows inside option A. The files are loaded from your GitHub images folder (see IMAGE_BASE in config.js).

            
question_number, answer_format, explanationoptionalKept as they are.

            
variant, has_images, image_typeignoredNot needed by the site.

          
        

      

      
Also accepted: a list of such objects (several exams in one file), or one flat list of questions where every question carries its own exam, branch, year and topic.
